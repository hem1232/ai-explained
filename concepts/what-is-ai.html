What is AI, Machine Learning, and Deep Learning?

Three words people use interchangeably that actually describe three nested things. Getting this straight makes almost everything else in AI click into place.

01 The plain-English version

Artificial intelligence is the broad goal: getting a computer to do something that normally requires human judgment — recognizing a face, translating a sentence, recommending a song.

Machine learning is the dominant way we build AI today: instead of writing explicit rules ("if the pixel pattern looks like this, it's a cat"), you show the computer thousands of examples and let it work out the rules itself.

Deep learning is a specific technique within machine learning that uses layered networks of simple math functions — loosely inspired by neurons — to learn from very large amounts of data. It's the technique behind almost every headline-making AI system since 2015.

02 The formal version

AI is a field, not a single method — it includes search algorithms, rule-based expert systems, planning, and learning-based approaches. Machine learning is the subfield concerned with algorithms that improve their performance on a task by processing data, without being explicitly reprogrammed for each new case. Formally, a model learns a function f(x) → y that maps inputs x to outputs y, by adjusting internal parameters to minimize error on example data.

Deep learning restricts that function to a specific shape: a stack of layers, each applying a linear transformation followed by a non-linear activation, trained via an algorithm called backpropagation (covered in the next concept).

03 How they nest

Deep learning is inside machine learning, which is inside AI. Every deep learning system is ML; not every ML system is deep learning; not all AI is ML at all (a chess engine's search algorithm is AI but not learning-based).

04 Worked example

Spam filtering, three ways

Rule-based AI (not ML): a programmer writes "if the email contains 'FREE MONEY' in all caps, flag it as spam." This is AI — it automates a judgment call — but there's no learning involved.

Classical ML: you feed the system 50,000 emails labeled spam/not-spam. It learns which word patterns statistically correlate with spam and builds its own rules — including ones a human might never think to write.

Deep learning: instead of hand-picking which word patterns matter, a neural network reads the raw email text and learns to represent meaning itself, catching subtler signals — tone, phrasing, structure — that simple word-counting would miss.

05 Where this shows up

Real-world use

Gmail's spam filter, Netflix's recommendations, and your bank's fraud detection are classical ML. ChatGPT, Midjourney, and Google Translate's newer versions are deep learning. Both count as "AI" — the term just tells you almost nothing about how the system actually works, which is why the more specific terms matter.

06 Common misconceptions

✕

"AI" and "machine learning" are the same thing. AI is the goal; ML is one (very popular) approach to reaching it. A calculator isn't AI. A hand-coded chess engine is AI but not ML.

✕

Deep learning is "better" than classical ML. Deep learning needs far more data and compute. For small structured datasets, a simple decision tree often outperforms a neural network.

✓

Correct framing: pick the narrowest technique that solves your problem. Reach for deep learning specifically when the data is unstructured (images, audio, free text) and abundant.
