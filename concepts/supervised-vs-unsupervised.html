Supervised vs. Unsupervised vs. Reinforcement Learning

Almost every ML system fits into one of three learning setups. The difference isn't the algorithm — it's what kind of feedback the model gets while training.

01 The plain-English version

Supervised learning is learning with an answer key: you show the model thousands of examples, each already labeled with the correct answer, and it learns to predict that answer for new, unlabeled examples.

Unsupervised learning has no answer key at all — you hand the model a pile of data and ask it to find structure on its own, like grouping similar customers together without being told what "similar" means.

Reinforcement learning is learning by doing: an agent takes actions in an environment and gets a reward or penalty, gradually learning which actions lead to better outcomes — closer to how a dog learns tricks than how a student studies flashcards.

02 The formal version

In supervised learning, training data is a set of pairs (x, y), and the model learns a function that minimizes the difference between its predicted ŷ and the true y. This covers both classification (discrete labels, like spam/not-spam) and regression (continuous values, like a price).

In unsupervised learning, training data is just x — no labels. Common tasks include clustering (grouping similar points) and dimensionality reduction (compressing data while preserving its structure).

In reinforcement learning, an agent observes a state, takes an action, and receives a reward, with the goal of learning a policy — a strategy for choosing actions — that maximizes cumulative reward over time. Unlike the other two, the model's own actions affect what data it sees next.

03 The flow

Three different feedback signals — a right answer, no signal at all, or a reward — produce three different kinds of learning.

04 Worked example

Same data, three ways

Take a dataset of 10,000 customer purchases. Supervised: if each purchase is labeled "fraud" or "legitimate," you can train a model to flag new fraudulent purchases. Unsupervised: with no fraud labels at all, you could still cluster customers into spending-behavior groups and flag anyone who doesn't fit any cluster as an anomaly. Reinforcement: a pricing agent that adjusts prices in real time and gets "reward" = revenue is learning a pricing policy through trial and error, not from a labeled dataset at all.

05 Where this shows up

Real-world use

Supervised learning powers most day-to-day ML products: spam filters, credit scoring, medical image diagnosis. Unsupervised learning shows up in customer segmentation, anomaly detection, and as a pretraining step for other models. Reinforcement learning is behind game-playing systems like AlphaGo, robotics control, and — notably — the RLHF step used to align chatbots like ChatGPT and Claude with human preferences.

06 Common misconceptions

✕

Unsupervised learning is "easier" because it needs no labels. It's often harder — without ground truth, there's no simple way to check if the model got it right.

✕

Reinforcement learning is just supervised learning with delayed labels. RL has to solve credit assignment (which of many past actions caused this reward?) and explore unknown strategies — problems supervised learning never faces.

✓

Correct framing: the choice isn't about which is "better" — it's about what kind of feedback your problem actually gives you. Most real products end up combining more than one.
