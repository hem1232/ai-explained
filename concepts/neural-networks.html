How Neural Networks Learn

A neural network is a chain of simple arithmetic — multiply, add, squash — repeated thousands of times. The "learning" is just slowly adjusting the numbers in that arithmetic until the output stops being wrong.

01 The plain-English version

Imagine you're guessing a house's price from its size. You start with a rule: price ≈ size × 200. You check it against a real sale, see you're off by a lot, and nudge the "200" up or down. Do that thousands of times across thousands of houses, and the number converges on something genuinely useful.

A neural network does exactly this, but with millions of adjustable numbers ("weights") instead of one, arranged in layers so it can capture patterns far more complex than a single multiplication.

02 The formal version

Each artificial neuron computes a weighted sum of its inputs, adds a bias, and passes the result through a non-linear activation function (like ReLU or sigmoid) — without that non-linearity, stacking layers would collapse into a single linear equation, no matter how many layers you added.

Neurons are arranged into an input layer, one or more hidden layers, and an output layer. Data flows forward through the layers (the "forward pass") to produce a prediction. The network compares that prediction to the true answer using a loss function, then backpropagation uses calculus (the chain rule) to work out how much each individual weight contributed to the error — and gradient descent nudges every weight slightly in the direction that reduces it.

04 Worked example

One tiny forward pass, with real numbers

Say we're predicting whether an email is spam using two inputs: x1 = number of exclamation marks (3), x2 = contains the word "free" (1 = yes). One neuron has weights w1 = 0.4, w2 = 1.2, and bias b = -1.0.

// weighted sum z = (x1 × w1) + (x2 × w2) + b z = (3 × 0.4) + (1 × 1.2) + (-1.0) z = 1.2 + 1.2 - 1.0 z = 1.4 // activation: sigmoid squashes z to a 0–1 probability sigmoid(1.4) = 1 / (1 + e^-1.4) ≈ 0.80

The network outputs 0.80 — "80% likely spam." If the email really was spam (true label = 1), the error is small and weights barely move. If it wasn't (true label = 0), backpropagation pushes w1, w2, and b down slightly so this email would score lower next time.

05 Where this shows up

Real-world use

This exact structure — layers, weights, backprop — sits underneath image classifiers on your phone (is this photo a dog?), credit-scoring models, and the first layer of every large language model. The architectures get far more elaborate (see: CNNs, Transformers), but the learning mechanism underneath is the same forward-pass-then-backprop loop.

06 Common misconceptions

✕

"The network understands the input." It's fitting a function to minimize error on training examples — there's no comprehension, just a very good statistical approximation.

✕

More layers always means a smarter model. Beyond a point, extra depth causes vanishing gradients and overfitting without careful techniques (residual connections, normalization) — bigger isn't automatically better.

✓

Correct framing: a neural network is a very flexible curve-fitter. Its power comes from having enough adjustable parameters and enough data to fit an extremely complex curve — nothing more mystical than that.
