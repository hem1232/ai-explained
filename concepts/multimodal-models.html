Multimodal Models

Most real-world understanding isn't confined to one type of data — a photo comes with a caption, a video comes with sound. Multimodal models are built to handle that mix natively.

01 The plain-English version

A multimodal model can take in — and sometimes produce — more than one type of data: text and images together, or text, images, and audio all at once, rather than being restricted to just one. Ask it about a photo, and it reasons about the image content directly, not from a text description someone else wrote.

The core challenge is getting fundamentally different kinds of data — pixels, sound waves, word sequences — into a shared representation the same underlying model can reason over consistently.

02 The formal version

A common approach: a modality-specific encoder (e.g. a vision Transformer for images, an audio encoder for sound) converts each input into embeddings in the same numerical format the language model already uses for text tokens. These embeddings are then fed into a shared Transformer alongside text token embeddings, letting self-attention relate a word directly to a specific region of an image or a specific moment in an audio clip.

Some multimodal systems are natively trained end-to-end on mixed data from the start; others are built by connecting separately pretrained encoders to a pretrained language model via a lightweight adapter layer, then fine-tuning the combination — a faster and cheaper approach that reuses existing single-modality models rather than training everything from scratch.

03 The flow

Different input types are each converted into the same kind of embedding space, letting one shared model reason across all of them together.

04 Worked example

Cross-modal attention in action

Given a photo of a kitchen and the question "is the stove on?", the model's attention mechanism connects the word "stove" to the specific image patches containing the stove — rather than the whole image indiscriminately — and connects "on" to visual cues like a lit burner or an illuminated display, combining both signals to produce a grounded answer instead of a generic guess.

05 Where this shows up

Real-world use

Multimodal models power visual question answering, image captioning, video understanding, accessibility tools that describe images for visually impaired users, and creative tools that generate images or video from a text prompt. Current frontier chat assistants (GPT-4/5-class, Claude, Gemini) are all multimodal, able to accept images and sometimes audio or video directly, alongside text.

06 Common misconceptions

✕

A multimodal model just runs a separate captioning tool and reads the caption as text. True multimodal models reason directly over visual embeddings alongside text — they can pick up on details a generic caption would miss entirely.

✕

Any model that outputs both text and images is "multimodal." A system that's really just two separate single-modality models glued together with no shared reasoning between them is a pipeline, not a genuinely multimodal model — the distinguishing feature is a shared representation the modalities interact within.

✓

Correct framing: multimodality is fundamentally about a shared reasoning space across data types, not just accepting multiple input formats at the API level.
