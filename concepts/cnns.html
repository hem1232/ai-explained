CNNs for Images

A regular neural network looking at a photo pixel-by-pixel would need an enormous number of weights and would learn nothing about shapes. CNNs fix this by learning small, reusable pattern-detectors.

01 The plain-English version

A Convolutional Neural Network scans an image with small sliding filters, each one learning to detect a simple visual pattern — an edge, a curve, a patch of color — and then combines those simple detections into progressively more complex ones: edges become shapes, shapes become object parts, object parts become whole objects.

The key insight is weight sharing: the same small filter is reused across the entire image, rather than learning a completely separate weight for every pixel position — this is both far more efficient and matches a real property of images, that a useful pattern (like an edge) can appear anywhere in the frame.

02 The formal version

A convolution slides a small filter (e.g. 3×3 pixels) across the input, computing a dot product at each position to produce a feature map highlighting where that pattern appears. Multiple filters per layer each learn to detect a different feature.

Pooling layers (commonly max pooling) downsample feature maps, reducing spatial size while keeping the strongest signals, which makes the network more robust to small shifts in where a feature appears. Stacking several convolution + pooling blocks builds a hierarchy: early layers detect edges and textures, deeper layers detect object parts and eventually whole objects, feeding into a final classification layer.

03 The flow

Each layer builds on the last: raw pixels → edges → shapes → object parts → a final label — a hierarchy of increasingly abstract features.

04 Worked example

What one filter actually detects

A simple 3×3 vertical-edge filter might look like:

[-1, 0, 1] / [-1, 0, 1] / [-1, 0, 1]

Slid across a region of the image where pixel brightness jumps sharply left-to-right (a vertical edge), this filter produces a large output value — that position "lights up" in the resulting feature map. Slid across a flat, uniform region, it produces close to zero. Training doesn't hand-design this filter — it emerges from backpropagation because detecting edges turns out to reduce classification error.

05 Where this shows up

Real-world use

CNNs power most of computer vision in production: photo tagging and search, medical imaging diagnosis, self-driving car perception systems, and manufacturing defect detection. Vision Transformers have started to compete with CNNs on large datasets, but CNNs remain dominant where data or compute is limited, thanks to their built-in assumption that nearby pixels are related.

06 Common misconceptions

✕

CNNs "see" images the way humans do. They detect statistical patterns useful for the training objective, which sometimes overlaps with human-perceived features and sometimes doesn't — this is why CNNs can be fooled by adversarial perturbations invisible to humans.

✕

Bigger filters always capture more detail. Larger filters have more parameters and can actually miss fine, local detail that small filters stacked in sequence capture more efficiently — this is why most modern CNNs favor small (3×3) filters stacked deep.

✓

Correct framing: CNNs work well specifically because images have spatial structure — nearby pixels are related — which is an assumption baked directly into the architecture, not learned from scratch.
