Attention, Intuitively

One mechanism, more than any other single idea, is responsible for the current era of AI. Before diving into the full Transformer, it's worth sitting with attention on its own.

01 The plain-English version

Attention lets a model, when processing one word, decide how much to "look at" every other word in the sentence — rather than reading strictly left to right and hoping earlier context survives, it can directly pull in whatever's relevant, no matter how far away it is.

It's a bit like how you read a sentence with a confusing pronoun: you don't just remember the sentence in order — you actively glance back to figure out what "it" refers to. Attention gives the model that same ability, but for every word, automatically, and learned from data rather than programmed by hand.

02 The formal version

For each token, self-attention computes a Query vector (what this token is looking for), and every token (including itself) offers a Key vector (what it contains) and a Value vector (what it contributes if attended to). The attention score between two tokens is the dot product of one's Query and the other's Key, scaled and passed through a softmax to produce weights that sum to 1.

The token's new representation is a weighted sum of all Value vectors, using those attention weights — so a token that's highly relevant contributes strongly to the result, and an irrelevant one contributes almost nothing. Running several of these attention computations in parallel (multi-head attention) lets the model track several different kinds of relationships at once — one head might track grammatical subject-verb agreement, another might track topical relevance.

03 The flow

Every token asks a question (Query), every token offers an answer (Key), and the token's new meaning is a blend of Values weighted by how well each answer matched the question.

04 Worked example

Attention weights, roughly

For the sentence "The animal didn't cross the street because it was too tired," attention weights for the word "it" (simplified, after softmax) might look like:

animal: 0.71 street: 0.09 tired: 0.14 (other tokens): 0.06

"Animal" dominates — the model has learned that tiredness is a property far more associated with animals than streets, so "it" ends up representing mostly "animal" once these weights blend the Value vectors together.

05 Where this shows up

Real-world use

Self-attention is the mechanism inside every Transformer, but the general idea — letting a model dynamically decide what's relevant rather than treating all input equally — has spread well beyond text, into vision Transformers, protein-folding models like AlphaFold, and multimodal systems that need to relate an image region to a specific word.

06 Common misconceptions

✕

Attention only looks backward, at earlier words. In most Transformer encoders, attention is bidirectional — full self-attention looks both forward and backward. Only decoder models used for text generation restrict attention to prior tokens, so the model can't "cheat" by seeing the future word it's supposed to predict.

✕

One attention head sees everything a model needs. A single head captures one type of relationship; real models use many heads in parallel, each free to specialize in a different pattern, then combine the results.

✓

Correct framing: attention is a learned, content-based way of routing information between positions in a sequence — a much more flexible mechanism than the fixed, sequential routing an RNN uses.
