Backpropagation, Step by Step

Backpropagation is the algorithm that made deep learning possible — an efficient way to answer one question, millions of times: exactly how much did this specific weight contribute to the error?

01 The plain-English version

After a network makes a prediction and you measure how wrong it was, you need to know how to adjust each of its (possibly billions of) internal weights to make it less wrong next time. Backpropagation is the method for computing exactly that, for every weight, efficiently.

It works backward from the output: the error at the final layer tells you how to adjust the weights feeding into it, which in turn tells you how much each earlier layer contributed, and so on back to the input — like tracing blame back through a chain of decisions.

02 The formal version

Backpropagation is an application of the chain rule from calculus. For a loss L and a weight w several layers back, the gradient ∂L/∂w is computed by multiplying together the local derivatives along the path from w to L — reusing shared intermediate results instead of recomputing them layer by layer, which is what makes it efficient enough to run on networks with billions of parameters.

Once every weight's gradient is known, gradient descent updates each weight by a small step in the direction that reduces the loss: w_new = w_old − learning_rate × gradient. The learning rate controls step size — too high and training becomes unstable, too low and training takes forever.

03 The flow

Error is computed once at the output, then distributed backward through every layer using the chain rule — one backward pass computes every weight's gradient.

04 Worked example

One weight update, with numbers

Say a weight w = 0.50 and its computed gradient is ∂L/∂w = 0.20 (increasing this weight would increase the error), with a learning rate of 0.1.

w_new = 0.50 − (0.1 × 0.20) = 0.50 − 0.02 = 0.48

That's one tiny nudge, on one weight, from one training example. A real network repeats this for every weight, across every training example, for potentially millions of steps — which is why training large models requires so much compute.

05 Where this shows up

Real-world use

Backpropagation itself is invisible to end users — it only happens during training, never during inference — but it's the mechanism underneath the training of literally every deep learning system in production today: image classifiers, language models, recommendation engines, and generative models.

06 Common misconceptions

✕

Backpropagation is a different algorithm from gradient descent. They're complementary: backprop computes the gradients; gradient descent uses those gradients to actually update the weights.

✕

Backpropagation guarantees finding the best possible model. It only guarantees moving in a direction that locally reduces error — it can get stuck in suboptimal solutions, which is why techniques like momentum and adaptive learning rates (Adam optimizer) exist to help it escape them.

✓

Correct framing: backpropagation is just efficient bookkeeping for the chain rule — it doesn't "understand" anything, it mechanically distributes blame for the error backward through the math.
