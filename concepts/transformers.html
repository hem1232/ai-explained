The Transformer Architecture

The architecture behind GPT, Claude, and essentially every modern language model. Its one big idea — self-attention — lets a model weigh every word against every other word at once, instead of reading one at a time.

01 The plain-English version

Older language models read text left to right, one word at a time, like a person with a very short memory — by the time they reached the end of a long sentence, they'd half-forgotten the beginning.

A Transformer instead looks at the whole sentence at once and asks, for every word: which other words in this sentence actually matter to understanding me? In "the trophy didn't fit in the suitcase because it was too big," the model has to figure out whether "it" refers to the trophy or the suitcase — self-attention is the mechanism that lets it weigh "trophy" more heavily than "suitcase" for that specific word.

02 The formal version

Text is first split into tokens (word pieces), and each token is mapped to a vector — a list of numbers — called an embedding, which captures aspects of its meaning. Because self-attention has no built-in sense of order, a positional encoding is added so the model knows word 3 came before word 7.

In self-attention, every token generates three vectors: a Query (what am I looking for?), a Key (what do I contain?), and a Value (what do I actually offer?). Each token's Query is compared against every other token's Key to produce attention scores — how much each other token should influence this one — which are then used to blend the Values into a new, context-aware representation. Stack this "attention → feed-forward" block a few dozen times, and you get a full Transformer. To generate text, the final layer predicts a probability distribution over the next possible token, one token at a time.

04 Worked example

Attention resolving a pronoun

Sentence: "The trophy didn't fit in the suitcase because it was too big."

When the model processes the token "it," self-attention computes a score between "it"'s Query and every other token's Key. Roughly:

// simplified attention scores for "it" (before softmax) "it" → "trophy" : 4.8 // high — likely referent "it" → "suitcase" : 1.2 "it" → "fit" : 0.6 "it" → "because" : 0.1

After softmax normalization, "trophy" ends up dominating the blended representation for "it" — the model has effectively resolved the pronoun, purely from co-occurrence patterns learned during training, with no hand-coded grammar rule involved.

05 Where this shows up

Real-world use

Every major chat-based AI system — GPT-4/5-class models, Claude, Gemini, Llama — is a Transformer, usually a "decoder-only" variant tuned for next-token generation. The same architecture (with a different assembly) also powers modern machine translation, and vision Transformers now compete with CNNs on image tasks.

06 Common misconceptions

✕

"Attention" means the model is paying attention like a person does. It's a specific, learned matrix-multiplication mechanism for weighting token relevance — the word is a useful metaphor, not a description of awareness.

✕

Bigger context window = the model "remembers" everything perfectly. Attention can weigh distant tokens, but in practice models still attend unevenly across very long contexts — information in the middle is often used less reliably than at the edges.

✓

Correct framing: a Transformer is a next-token predictor trained on enormous text corpora. Fluent, coherent output emerges from that objective at scale — it's not a separate "understanding module" bolted onto prediction.
